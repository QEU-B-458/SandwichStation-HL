## Directory Locations

Species files are organized across:

- `Content.Client/_species/` — client-side systems and UI
- `Content.Server/_species/` — server-side systems
- `Content.Shared/_species/` — shared components and systems
- `Resources/Prototypes/_species/` — YAML entity/species/organ prototypes
- `Resources/Textures/_species/` — sprites (RSI files)
- `Resources/Locale/en-US/_species/` — localization strings
